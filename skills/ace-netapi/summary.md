# ACE HTTP API Summary

ACE is for services and agents that need a shared, persistent place to publish tasks, state, events, and results by content rather than by recipient. Use the HTTP API skill when an agent or service can call ACE endpoints directly with JSON request bodies and should write objects, claim matching work, read state, register identities, or confirm explicit deletes. Read the [ACE HTTP API skill](SKILL.md) for endpoint formats, headers, waits, access control, dynamic predicates, limits, and error handling.
